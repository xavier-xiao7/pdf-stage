# 1.0.1 验证说明

## 环境

- Windows 11 x64，OS build 10.0.26200。
- .NET Framework release 533509。
- PDFium 157.0.8100.0，Windows x64，无 V8 / XFA。

## 核心检查：48 项

覆盖实际 PDF 渲染及像素结果、中文文件名、含空格路径、横版/竖版/方形页面、损坏/空页/不存在文件、失败时保留原文档。

窗口检查覆盖无标题栏和不透明窗口、Windows `PrintWindow` 捕获、键盘/鼠标翻页、首末页边界、滚轮节流、黑屏恢复、窗口比例、置顶、拖动不误翻页，以及真实鼠标输入触发的原生窗口缩放。

交互检查覆盖全局快捷键注册/释放，在讲稿窗口保留焦点时翻页；200 页 PDF 拖放，快速发出 150 次页码请求后到达最新目标页，以及连续更换多个文件后显示最后选择的文档。

## 菜单回归：18 项

使用真实 `Application.Run` 消息循环。旧版在相同用例中抛出 `ObjectDisposedException`，调用栈包括 `ToolStripDropDown.SetVisibleCore` 和 `ReparentToDropDownOwnerWindow`，与用户崩溃记录一致。

修正版覆盖菜单失焦关闭、Esc 关闭、点击外部关闭、切换其他窗口后经过 WinForms 菜单消息过滤器关闭；150 轮开关菜单、移动、缩放、翻页；实际菜单项点击翻页、适配比例、打开/取消跳页对话框、最小化和退出。

## 画面检查与边界

已查看欢迎界面、横版演示页、竖版文档的窗口捕获图。最终可执行文件也已实际启动并操作。

尚未端到端验证：Zoom 会议接收端、Windows 10 实机、多显示器混合 DPI、所有加密方式和所有第三方生成的 PDF。以上检查不构成对所有环境的兼容保证。

运行复现测试请参考 README 的 `scripts/test.ps1`。这些测试需要交互式桌面，会移动鼠标，结果不适用于无桌面的 CI 环境。
