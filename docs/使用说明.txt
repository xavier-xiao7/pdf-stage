PDF Stage · 无边框 PDF 演示
版本 1.0.1  |  Windows 10 / 11，64 位

1.0.1 修复：右键菜单关闭后再翻页、移动、缩放或切换窗口时可能崩溃。
菜单改为随主窗口管理，关闭完成后再执行命令；新增异常诊断日志。

你要的使用方式
打开 PDF 后，窗口内只显示页面，没有标题栏、工具栏、页码浮层。
窗口仍可自由移动、调整大小，让桌面旁边留出讲稿和资料的位置。
页面完整显示并保持原比例，不裁切、不拉伸。

开始使用
1. 将整个压缩包解压到一个文件夹。双击 PdfStage.exe。
2. 点击“打开 PDF”，或者把 PDF 文件拖进窗口。也可以按 Ctrl + O。
3. 按住页面拖动来移动窗口；拖动四边或四角来调整窗口大小。
4. 按 Ctrl + 1，让窗口尺寸贴合当前 PDF 页面的比例。
5. 在 Zoom 的“共享屏幕”中选择标题以“PDF Stage”开头的应用窗口。
   请选单个应用窗口；共享整个桌面会让观众看到桌面上的其他资料。
6. 在演示窗口旁边打开你的讲稿。按方向键或单击页面开始翻页。

可先打开同文件夹里的 Demo.pdf 试用。
此程序完全在本机读取 PDF，不会上传文件，不需要登录或网络。
无需安装；保留 PdfStage.exe、pdfium.dll 和 licenses 文件夹在一起。

看讲稿时也能翻页
在 PDF Stage 中按 Ctrl + H，或右键勾选“看讲稿时也能翻页”。
随后即使鼠标焦点在其他应用里，也可以使用：
Ctrl + Alt + →          下一页
Ctrl + Alt + ←          上一页
再次按 Ctrl + H 可关闭。每次启动默认关闭，不会长期占用快捷键。
若这些组合键已被其他软件占用，程序会提示；普通翻页仍然可用。

窗口与画面
• 打开后不会自动占满屏幕，也不会强制置顶。
• 右键菜单提供“摆在屏幕左侧 / 右侧”，方便给讲稿留位置。
• 会记住窗口的位置和大小。换显示器后会把窗口调整回可见区域。
• 不同页面比例会产生黑边，这是完整显示的结果；Ctrl + 1 可减少黑边。
• PDF 自身的白边属于文件内容，本软件不会自动裁掉。
• 翻到最后一页不会自动跳回第一页。
• 连续滚轮输入有短暂节流，避免一次滚动跳过多页。

Zoom 使用提示
• 共享前完成文件选择、窗口摆放，并关闭右键菜单。
• 选择“PDF Stage”对应的单个窗口，不要选择“整个屏幕”。
• 共享期间保持窗口打开，不要最小化；不同共享方式下最小化可能暂停画面。
• 菜单、密码输入和帮助对话框可能进入共享画面；需要时先暂停共享。
• 是否捕获鼠标、是否把同一应用的多个窗口一起共享，由 Zoom 设置决定。
• 本机已验证 Windows 窗口捕获能正常读取页面；尚未在实际 Zoom 会议里验证。
  正式演示前，建议开一次测试会议，用另一台设备确认观众端画面。

范围
• 第一版只演示 PDF；PowerPoint 文件需先导出为 PDF。
• 支持普通密码保护 PDF，输入正确密码后打开。
• 不播放 PDF 中的视频、脚本和交互表单，不提供批注、编辑或 OCR。
• 文件大小上限为 1 GB；单页渲染尺寸最多 4096 × 4096 像素。
• 实际测试环境为 Windows 11 x64；Windows 10 x64 为目标支持环境，未单独实机测试。
• 使用 Windows 自带的 .NET Framework 4.x。当前机器已具备运行环境。

重新编译
在退出 PDF Stage 后，在 PowerShell 中运行 source/build.ps1。
脚本使用 Windows 的 .NET Framework C# 编译器，输出到软件所在文件夹。
仅编译源码不会重新下载 PDF 引擎，请保留同包内的 pdfium.dll。

窗口位置保存在：%LOCALAPPDATA%\PdfStage\window.txt。
发生异常时，诊断记录保存在：%LOCALAPPDATA%\PdfStage\errors.log。
关闭后删除本文件夹即可移除软件；可同时删除上述设置文件夹。
