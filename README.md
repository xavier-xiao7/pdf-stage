# PDF Stage · 无边框 PDF 演示

**把 PDF 放进一个可自由缩放的演示窗口，为讲稿留出桌面空间。**

PDF Stage 是一个轻量的 Windows 桌面工具：打开 PDF 后，窗口只显示文档页面，没有标题栏、工具栏或常驻页码。你可以拖动、缩放这个窗口，用鼠标或键盘翻页，并在 Zoom 中单独共享它。

它适合这样的场景：**观众看演示，你在同一块屏幕上看讲稿、会议资料和聊天窗口。**

## 使用场景

### 1. Zoom 演示，同时看讲稿

你只有一块显示器，需要向观众展示 PDF 幻灯片，但又想在旁边查看讲稿。

1. 在 PDF Stage 中打开演示 PDF，把窗口摆到屏幕左侧。
2. 在右侧打开 Word、记事本、浏览器或其他讲稿工具。
3. 在 Zoom 的共享选择器中，选择 **PDF Stage 对应的单个应用窗口**。
4. 观众接收这个窗口的画面；你在本地保留讲稿空间。
5. 若焦点需要留在讲稿里，可启用全局翻页快捷键。

示意布局：

```text
┌─────────────────────────── 你的桌面 ───────────────────────────┐
│                                                              │
│  ┌─────────────────────────┐  ┌───────────────────────────┐  │
│  │                         │  │  讲稿 / 备注 / 参考资料   │  │
│  │      PDF Stage          │  │                           │  │
│  │    这个窗口被共享       │  │  由你在本地查看           │  │
│  │                         │  │                           │  │
│  └─────────────────────────┘  └───────────────────────────┘  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**共享范围由 Zoom 设置决定。** 要实现这个布局，请选择单个应用窗口，而不是整个桌面。菜单、对话框和同应用的其他窗口是否一起被捕获，也取决于共享方式。参阅 [Zoom 官方的单窗口共享介绍](https://www.zoom.com/en/products/virtual-meetings/features/screen-sharing/)。

### 2. 线上教学、答辩和技术讲解

将课件、论文图表或技术方案导出为 PDF，用干净的窗口展示；旁边放教学提纲、计时工具或问答记录。鼠标单击、滚轮、方向键和翻页键都可使用。

### 3. 屏幕录制中的独立文档画面

将 PDF Stage 作为窗口采集目标，录制不带阅读器工具栏的文档画面。窗口可匹配页面比例，方便布置录制画面。其他会议和录屏工具的兼容性需要各自实测，目前没有声称全部兼容。

### 4. 从 PowerPoint 导出后的窗口化演示

如果材料原本是 PowerPoint，先导出为 PDF，再用 PDF Stage 打开。页面布局以导出结果为准；PowerPoint 动画、视频和转场不会保留为本软件可播放的效果。

## 功能

| 功能 | 行为 |
| --- | --- |
| 无边框窗口 | 打开文档后只显示页面，无标题栏、工具栏、常驻浮层 |
| 自由移动与缩放 | 按住页面拖动窗口，拖四边或四角调整尺寸 |
| 等比完整显示 | 保持页面比例，不裁切；比例不一致时留黑边 |
| 一键匹配比例 | `Ctrl + 1` 调整窗口以贴合当前页面比例 |
| 多种翻页方式 | 单击、滚轮、方向键、空格、Page Up / Down、鼠标侧键 |
| 跨窗口翻页 | 可选启用 `Ctrl + Alt + ← / →`，焦点在讲稿窗口也能翻页 |
| 快速布局 | 右键将窗口放在屏幕左侧或右侧，可切换置顶 |
| 黑屏暂停 | `B` 暂时隐藏页面，再按一次恢复 |
| 本地文件 | 打开文件、拖入 PDF、命令行传入路径；无需登录或联网 |
| 保留窗口位置 | 记住窗口大小及位置，恢复时限制在可见工作区 |
| 错误处理 | 无效文件打开失败时保留原文档，异常会写入本地日志 |

普通翻页键在 PDF Stage 获得焦点时生效；全局翻页需要手动启用。最后一页不会自动循环到第一页。

## 下载与运行

1. 打开 [Releases](https://github.com/xavier-xiao7/pdf-stage/releases/latest)。
2. 下载 `PdfStage-1.0.1-Windows-x64.zip`，**解压整个压缩包**。
3. 双击解压后的 `PdfStage.exe`。
4. 点击“打开 PDF”、按 `Ctrl + O`，或将 PDF 拖进窗口。
5. 用附带的 `Demo.pdf` 可先试用三页示例。

软件为便携版，无需安装。请把 `PdfStage.exe`、`pdfium.dll` 和 `licenses/` 保留在一起；不要只复制 EXE。

### 系统要求

- Windows 10 / Windows 11，x64。
- .NET Framework 4.8 或更新的兼容版本。
- 不需要安装 PowerPoint、Adobe Reader、Python、Node.js 或浏览器运行时。
- 已在 Windows 11 x64 上实测；Windows 10 是目标支持环境，尚未单独实机验证。
- 当前发布包未做代码签名。

Node.js 仅在开发者生成测试 PDF 时使用，普通用户运行软件不需要它。

## 快捷键与鼠标操作

| 操作 | 快捷方式 |
| --- | --- |
| 下一页 | 单击、滚轮向下、`→`、`↓`、`Space`、`Page Down` |
| 上一页 | `Shift + 单击`、滚轮向上、`←`、`↑`、`Page Up`、`Backspace`、`Shift + Space` |
| 第一页 / 最后一页 | `Home` / `End` |
| 打开 PDF | `Ctrl + O` |
| 跳转页码 | `Ctrl + G` |
| 窗口贴合页面比例 | `Ctrl + 1` |
| 切换窗口置顶 | `Ctrl + T` |
| 启用 / 关闭全局翻页 | `Ctrl + H` |
| 全局上一页 / 下一页 | 启用后使用 `Ctrl + Alt + ← / →` |
| 黑屏 / 恢复 | `B`；黑屏时 `Esc` 也可恢复 |
| 菜单 | 右键 / `Esc` |

| 退出 | `Alt + F4`，或右键菜单“退出” |

| 鼠标侧键 | 后退侧键上一页，前进侧键下一页 |

### 焦点在讲稿里时怎么翻页？

先在 PDF Stage 中按 `Ctrl + H`，或右键勾选“看讲稿时也能翻页”。然后切回讲稿窗口，用 `Ctrl + Alt + ← / →` 翻页，输入焦点会留在讲稿里。

该功能每次启动默认关闭。若组合键被其他软件占用，程序会提示；普通翻页仍可使用。

## Zoom 使用步骤与边界

1. **共享前准备好页面。** 打开 PDF、摆放窗口，关闭右键菜单和帮助对话框。
2. **选择单个窗口。** 在 Zoom 里选择标题以 `PDF Stage` 开头的窗口，避免误选整个桌面。
3. **保持演示窗口打开。** 共享期间不要最小化，某些共享方式会因此停止更新画面。
4. **查看讲稿。** 把讲稿放在旁边；必要时启用全局翻页。
5. **正式会议前预演。** 用另一台设备或另一位参会者确认收到的画面范围。

本项目已验证 Windows `PrintWindow` 能捕获页面；**实际 Zoom 会议接收端尚未验证**。应用窗口采集行为还受 Zoom 版本、采集设置和显卡环境影响。PDF Stage 不控制 Zoom，也不保证菜单、对话框或其他重叠窗口一定被过滤。

## 页面比例与黑边

PDF Stage 始终优先完整显示页面。16:9 页面放入 16:9 窗口时可以铺满；竖版页面放入宽窗口时，两侧会有黑边。

按 `Ctrl + 1` 可让窗口贴合当前页面比例。受到最小窗口尺寸和显示器工作区限制时，仍可能有少量黑边。PDF 文件自身的白边属于页面内容，不会自动裁掉。

## 已知限制

- 只打开 PDF，不直接打开 `.ppt` / `.pptx`。
- 不提供编辑、批注、OCR 或文本搜索。
- 不播放嵌入视频，不执行 PDF JavaScript，不支持 XFA 交互表单。
- 可输入密码打开普通密码保护 PDF，但未覆盖验证所有加密方式。
- 文件大小上限 1 GB；单页渲染每个方向最多 4096 像素。
- 复杂页面会异步渲染，完成前保留上一幅画面；不承诺任意文件都即时翻页。
- 多显示器混合 DPI、Windows 10 实机、各种会议 / 录屏工具仍需进一步验证。

## 本地数据与诊断

应用本身没有联网、登录、文件上传或遥测功能。首次从源码构建时，构建脚本需要下载 PDFium。

| 路径 | 用途 |
| --- | --- |
| `%LOCALAPPDATA%\PdfStage\window.txt` | 窗口位置和大小 |
| `%LOCALAPPDATA%\PdfStage\errors.log` | 发生异常时的版本、时间和异常堆栈 |

错误日志超过约 1 MB 后会清空再写入。日志不主动记录 PDF 正文或密码；异常信息可能包含文件路径，提交问题前请检查并去掉个人信息。

移除软件时，关闭窗口后删除解压文件夹即可；需要清理设置时再删除上述 `PdfStage` 设置目录。

## 从源码构建

不需要 Visual Studio 或完整 .NET SDK。构建脚本使用 Windows .NET Framework 自带的 C# 编译器，下载固定版本 PDFium 并核验 SHA-256。

```powershell
git clone https://github.com/xavier-xiao7/pdf-stage.git
cd pdf-stage
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
.\dist\PdfStage\PdfStage.exe .\examples\Demo.pdf
```

产物位于 `dist/PdfStage/`。编译为 x64；首次构建需要访问 GitHub 下载依赖。

创建便携压缩包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

会生成 `dist/PdfStage-1.0.1-Windows-x64.zip` 和同名 `.sha256` 校验文件。

### 运行测试

测试需要 Windows 交互式桌面以及 PATH 中可用的 Node.js。测试会临时打开窗口、移动鼠标并发送快捷键，请在运行时暂停其他鼠标键盘操作。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

测试包括 PDF 渲染、边界翻页、拖放、原生缩放、全局快捷键和菜单生命周期回归。结果保存在 `.cache/tests/`。

已执行的 1.0.1 验证包括 **48 项核心检查 + 18 项菜单回归检查**，其中包含 **150 轮开关菜单、移动、缩放和翻页的组合操作**。这说明这些具体路径已验证，不代表所有 PDF 和运行环境都经过测试。详见 [验证说明](docs/validation.md)。

## 实现与目录

程序使用 **C# + WinForms + PDFium**。页面渲染在单独的串行工作线程中执行，界面线程负责交互与绘制；新请求替换尚未处理的翻页请求，过期结果不会覆盖新页面。窗口使用原生调整大小机制，同时将整个客户区用于显示页面。

```text
src/                       程序源码、清单和图标
  Program.cs               启动、DPI 和异常入口
  StageForm.cs             窗口、菜单、翻页与快捷键
  PdfEngine.cs             PDFium 调用与串行渲染线程
  Diagnostics.cs           本地异常日志
scripts/                   依赖下载、构建、打包和测试脚本
tests/                     核心测试、菜单回归、测试 PDF 生成器
examples/Demo.pdf          三页演示样本
docs/                      预览图片、使用说明和验证记录
THIRD_PARTY_NOTICES.md      第三方组件来源与许可说明
```

## 1.0.1 修复了什么？

1.0.0 在右键菜单的 `Closed` 事件里立即释放菜单，而 WinForms 在该事件之后仍需访问菜单窗口句柄，导致 `ObjectDisposedException`，可能在切换窗口或后续交互时退出。

1.0.1 改为复用菜单、随主窗口统一管理生命周期，并在菜单完成关闭后才执行命令。旧版已复现相同异常，新版通过对应回归；同时增加了异常日志。参见 [更新记录](CHANGELOG.md)。

## 常见问题

**窗口没有标题栏，如何移动或退出？** 直接按住页面拖动；`Alt + F4` 退出，或使用右键菜单。

**为什么会有黑边？** 窗口和页面比例不同。按 `Ctrl + 1` 匹配比例，PDF 原有白边不会被裁切。

**为什么看讲稿时方向键不翻页？** 普通方向键作用于当前窗口。启用 `Ctrl + H` 后改用 `Ctrl + Alt + ← / →`。

**为什么报找不到 PDF 引擎？** 请完整解压下载包，确保 `pdfium.dll` 和 `PdfStage.exe` 在同一目录。

**旧版曾发生崩溃，该下载哪个？** 使用 1.0.1 或之后的版本，替换整个便携文件夹。复现问题时可附上版本、操作步骤和去掉个人信息的错误日志。

**能否用在 Teams、腾讯会议或 OBS？** 可以尝试选择该应用窗口；本项目尚未验证这些工具的端到端兼容性。
